# 隐私政策

**最后更新：2026-10-26**　·　适用于 xbot 的全部客户端（HarmonyOS 应用、Web UI、CLI）与 xbot 后端程序

## 一句话总结

xbot 是**自托管软件**：**官方不运行任何服务器、不提供任何后端接口、不收集任何数据**。
你的数据只存在**你的设备**与**你自己部署的 xbot 实例**里。本软件以 **MIT** 协议开源，全部代码可自行审计。

## 1. 我们明确**不**收集什么

| 类别 | 是否收集 |
|---|---|
| 账号 / 手机号 / 邮箱 / 身份证 | ❌ 无账号体系 |
| 设备标识符 / 广告 ID / IMEI / OAID | ❌ |
| 位置信息 | ❌ |
| 使用埋点 / 行为分析 / A/B 分流 | ❌ |
| 崩溃上报 / 遥测 / 性能数据回传 | ❌ |
| 会话内容、文件、Shell 输出、模型密钥 | ❌ 不上传任何官方服务器 |
| 健康数据 | ❌ 不上传（详见第 4 节） |

> 官方**没有**"云服务"、没有中转服务器、没有 API 网关，也不存在"官方账号"。
> 你在 App 里填的服务器地址，指向的必须是**你自己部署**的实例。

## 2. 数据实际存在哪里

| 数据 | 存放位置 |
|---|---|
| 服务器地址 + 访问令牌 | 你的设备（本地偏好存储） |
| 会话、附件、工具执行结果、插件数据 | 你**自建**的 xbot 实例（你的服务器或本机） |
| 模型推理请求 | 你在实例里**自己配置**的模型服务商（OpenAI / Anthropic / 自建 vLLM 等），按其条款处理 |
| 健康数据（可选） | 你的设备 + 你的自建实例，详见第 4 节 |

我们（作者）无权、也无法访问上述任何一处数据。

## 3. ⚠️ 不要相信别人的服务器

**任何人提供的 xbot 实例，其管理员都能看到你的全部会话、文件内容与工具执行结果（含 Shell 命令与输出）。**

- ✅ 只连接**你自己部署**的实例；
- ⛔ 不要使用陌生人分享的"公共 xbot 服务器"或演示站登录真实信息；
- ⚠️ 团队共用时，请假定实例管理员可见一切，并按此决定是否在其中处理敏感数据；
- 我们不对任何第三方实例的数据安全、留存与删除负责。

## 4. 健康数据（HarmonyOS Health Service Kit）

仅当你**在系统授权弹窗中主动勾选并同意**后，App 才会读取你选择的类型（例如步数、心率、睡眠、锻炼记录、身体测量）。

- **用途仅限两项**：① 在你自己的 App 界面展示**你本人**的趋势与统计；② 当你主动发起对话时，把相关数据交给**你自己配置**的模型做问答与摘要；
- **不做**医疗诊断或治疗建议；**不用于**广告、用户画像、风控、保险定价；**不向**任何第三方共享、出售或转让；
- 数据**不在官方服务器留存**（官方没有服务器）；只存在你的设备与你的自建实例；
- **随时撤回**：系统「设置 → 隐私 → 授权管理」中关闭对应权限即可，App 立即停止读取；已同步到自建实例的历史数据可在实例数据目录中删除；
- 卸载 App 或删除自建实例的数据目录即彻底删除，我们不另存任何副本。

## 5. 系统权限与用途

| 权限 | 用途 |
|---|---|
| `ohos.permission.INTERNET` | 连接**你自己**的 xbot 实例 |
| `ohos.permission.GET_NETWORK_INFO` | 判断网络可用性，给出离线提示 |
| `ohos.permission.VIBRATE` | 消息到达触感提醒 |
| Health Kit 数据权限（可选） | 见第 4 节；**不授权也能正常使用** App 的其它功能 |

## 6. 儿童隐私

本软件不面向 13 岁以下儿童。自托管形态下，实例管理员需自行确保符合其所在地区的合规要求。

## 7. 政策变更

本政策的每次修改都会以 Git 提交形式发布在仓库中（可逐行 diff 审计）。涉及数据处理方式的重大变更会在 App 与仓库 Release 说明中提示。
