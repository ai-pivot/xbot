# Web 渠道

浏览器聊天界面。支持用户注册/登录、邀请制和 Persona 隔离。

**需要 Server 模式。**

## 配置

```json
{
  "web": {
    "enable": true,
    "port": 8082
  },
  "admin": {
    "token": "your-secret-token"
  }
}
```

| 字段 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `enable` | ✅ | `false` | 启用 Web 渠道 |
| `host` | ❌ | `""` | 监听地址（空 = 所有接口） |
| `port` | ❌ | `0` | 监听端口 |
| `static_dir` | ❌ | 自动检测 | 前端静态文件目录 |
| `upload_dir` | ❌ | `""` | 上传文件自定义目录 |
| `persona_isolation` | ❌ | `false` | 启用后每个 Web 用户的 persona 互相隔离 |
| `invite_only` | ❌ | **`true`** | 禁止自主注册。**默认 true（安全默认）**——第一个账号仍可注册（首用户引导），之后只能由管理员创建账号。显式设为 `false` 才会重新开放公开注册。 |

## Web UI 安装

Server 模式安装时，安装器会自动下载 Web UI 到 `~/.xbot/web/dist/`。

如果需要手动安装：

```bash
# 下载对应版本的 web 压缩包并解压到 ~/.xbot/web/dist/
```

## 访问

启动 Server 后，在浏览器中打开 `http://your-server:8082`。

## 消息输入框

> **新建会话**：可选择工作目录；**目录不存在时会自动创建**（含多级父目录）。若路径被文件占住或没有权限，会明确报「工作目录设置失败」，不会静默用错目录。


富文本（WYSIWYG）编辑器，支持 Markdown 快捷语法（`**粗体**`、`-` 列表等）与链接：

| 功能 | 说明 |
|------|------|
| 链接 | 输入 `https://…` 后跟空格自动成链；粘贴链接/Markdown 链接语法（`[文字](URL)`）实时渲染；链接以主题色高亮显示 |
| 链接编辑 | 选中文本浮现工具栏（加粗/斜体/删除线/行内代码/链接）；`Ctrl/Cmd+K` 快速添加或修改链接，支持一键解除 |
| 文件上传 | **支持任意类型文件**（无类型白名单）。点击 📎 选择文件、直接**粘贴**（截图自动上传）或**拖拽**到输入框，文件作为附件随消息发送 |
| 上传限制 | 单文件 10MB（仅限大小，不限类型） |
| 终端命令 | 以 `!` 开头的消息会作为 **shell 命令在沙箱中直接执行**，输出以对话消息返回（跳过 AI），例如 `!ls -la`、`!git status`、`!docker ps`。输入框在 `!` 命令草稿时会给出提示；`![...]`（粘贴的截图等 Markdown 图片语法）**不会**被当作命令 |

## 回答批注

选中助手正文后，选区旁会直接出现评论图标，点击即可添加批注，**不需要右键，也不必等待输出结束**。选中正在生成的文字后，回复继续输出，所选引用保留为快照，不会因为后续文本更新而撤掉评论按钮。手机长按选中文字后，可用原生选区手柄调整范围。编辑器只显示所选片段的只读快照，编辑框和预览均不显示轮次、迭代和字符计数。评论框按 **Enter** 确认、**Shift+Enter** 换行，输入法选词不会误确认；确认仅添加草稿，不会发送消息。点击别处、通过键盘取消选区、滚动、调整视口或切换会话后，图标消失；右键菜单仍用于复制和链接操作。思考、工具输出和用户消息不开放批注。

勾选确认后，批注进入**现有输入框内部的计数 chip**，与附件同层；点击计数可预览、编辑和删除。添加或编辑不会覆盖正文、链接、图片和附件，也不会触发 Agent。可仅发送批注，或与正文、附件一起发送；Agent 忙碌时按普通反馈排队。批注不能与 slash/shell 命令、目标模式或插话模式混用。

已确认批注按登录用户名和渠道/会话保存在当前浏览器，刷新可恢复，退出登录清理。发送被拒绝时保留草稿，迟到的成功响应不会清空后来新写的正文。限制：每次 10 条，引用 6000 个 Unicode code points，评论 2000 个，总计 20000 个；超限明确拒绝，不截断。

发送内容采用 `<response-annotations>` 包裹的 JSON 数组 `{text, annotation, source}`，再通过 `# My request:` 携带输入框原有正文。Agent 会收到引用原文、用户评论以及已知的来源位置（轮次、迭代、消息 ID 和选区偏移）。偏移是渲染正文拼接 DOM 文本中从 0 开始、左闭右开的 UTF-16 位置，不是原始 Markdown 的偏移。旧草稿缺失位置仍可使用，不会编造。提示明确区分历史引用与本次用户指令。

聊天气泡仍只显示正文、引用和评论，**不显示 XML 或来源标签**；复制或编辑消息时保留实际发送的 XML prompt。反馈沿用现有历史和队列。来源位置只是选中时的快照，不是撤回后的永久链接或锚点。首版不包含私有备注、服务器/跨设备草稿、原文高亮或重启后持久化发送去重。输入框仍挂载时，内容未变的重试复用请求 ID，受服务器既有去重窗口约束；刷新或重启后的恢复不保证 exactly-once。

## 会话列表（按项目组织）

会话列表默认**按项目组织** —— 项目 = 该会话的**工作目录**（后端 `tenants.cwd`）。同一目录下的会话归为一组，组头显示**项目名 + 会话数**（悬停可看完整路径；没有工作目录的会话归入「未设置工作路径」）。

列表上方的视图栏可切换组织方式（桌面左栏与手机抽屉完全一致）：

| 分类 | 分组键 |
|------|--------|
| **项目**（默认） | 工作目录 |
| 状态 | 运行中 / 等待输入 / 排队 / 未读 / 空闲 / 错误 |
| 时间 | 今天 / 昨天 / 更早 |

**折叠 / 展开**：点组头折叠或展开该组；点视图栏右侧的「全部折叠 / 全部展开」一次改所有组。折叠状态**按项目记住**（存 `localStorage`，纯前端、不跨设备同步），刷新或重开面板后保持。

> 从旧版本升级：旧默认是「按时间」，首次打开会自动切到「按项目」**一次**；此后你手动选择的分类不会再被改动。

## Invite-Only 模式

当 `invite_only: true` 时：

- 新用户无法自主注册（返回 403）
- 管理员可通过飞书渠道的管理命令或直接操作数据库创建账号
- 适合内部团队使用

### 首用户引导

全新部署还没有任何账号，因此第一次注册会被放行——该账号即成为管理员。注册页会明确提示「首次设置 · 仅此一次」，并说明注册随后自动关闭，访客不必猜测注册接口是否对所有人开放。账号创建后，`/register` 显示 invite-only 通知，登录页也不再显示注册入口。

## UI 模式（自动 / 桌面 / 移动端）

Web UI 有桌面与移动两套外壳，默认按视口宽度自动选择（≤767px 用手机外壳）。窄屏平板、横屏手机或桌面窄窗口边缘场景下，自动判断未必符合预期，因此可以在**设置 → 外观 → UI 模式**手动固定：

| 模式 | 行为 |
|------|------|
| 自动（默认） | 跟随视口断点（≤767px = 手机外壳） |
| 桌面 | 始终使用桌面外壳（多面板 / Dockview 布局） |
| 移动端 | 始终使用手机外壳（抽屉会话 + 底部导航） |

偏好存本地（`localStorage`）即时生效，并同步到服务端（`web:ui:ui-mode`），换设备/浏览器后保持一致。该设置只切换**外壳**，不改变 CSS 断点——在窄屏上强制桌面外壳会得到被压缩的桌面布局。

## Persona Isolation

当 `persona_isolation: true` 时：

- 每个 Web 用户的系统人格（persona）互相隔离
- 用户 A 设置的 Agent 行为不影响用户 B
- 适合多租户场景

## 文件存储（上传的图片/附件存哪里）

**Web 设置 → 存储**可切换后端，**保存即生效，无需重启**：

| 后端 | 说明 | 保留策略 |
|---|---|---|
| **本地**（默认，免配置） | 上传写 `<XBOT_HOME>/uploads/`，由同源 `/api/files/download` 读盘返回 | 每次上传后只保留**最新 500 个**（按文件修改时间；没有时间上限，等于 `500 ÷ 日均上传数` 天） |
| **阿里云 OSS** / **腾讯云 COS** | S3 兼容：复用同一组凭据，**endpoint 由 region 自动推导**（`cn-hangzhou` → `oss-cn-hangzhou.aliyuncs.com`；`ap-guangzhou` → `cos.ap-guangzhou.myqcloud.com`），也可手填 endpoint 覆盖（MinIO/R2/自建网关） | 云端**不会自动过期** |
| **七牛 Kodo** / **S3 兼容** | 对象存储为权威；本地仍留一份副本供模型拿到真实路径 | 云端**不会自动过期**（如需过期请在云控制台设 lifecycle） |

- 上传：编辑器里粘贴/拖拽 → `POST /api/files/upload`（≤10MB，类型不限制）→ 返回 `upload_key`，消息正文里只存**相对引用** `![name](/api/files/download?key=…&inline=1)`（不存 base64；取不到时显示占位）。
- 取回：`GET /api/files/download?key=…`（默认「下载」，加 `&inline=1` 才内联渲染）。
- 凭据在读取时**打码**（`AKID****`），回写掩码值不会覆盖真实密钥；切到云后端前必须给齐 access/secret/bucket（阿里云 OSS / 腾讯云 COS 还需 region，除非手填 endpoint），否则会**拒绝保存**（避免半配置把上传打断）。
- 想让模型"看到"图片，还需在 **设置 → LLM → 模型行 → 视觉输入（多模态）** 打开对应模型的开关。
